# New era to make apps

Definitely, the way to develop apps has changed forever. I have been using AI as a tool to do my job since to appear of ChatGPT maybe about 2 years ago, I remember the problem: a pipeline written in python to load data from raw files and merge it with data from SQL queries, convert it to data frames with pandas, and do some calculations with NumPy, apply and validate formats and save into merged CSV files. Before this task I haven't touched python in a job, but with a clear idea about what I had to do and with a few prompts I was able to solve the problem, at that moment the work was more slowly and was necessarily to see the code and modify it by hand in many times, about 3 weeks to complete the task, validate and automate it [IN PROGRESS]
